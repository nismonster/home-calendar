Privacy Policy

Last updated: September 27, 2026

Home Calendar is a personal app used only by its owner on a device in the owner's home.

What data the app accesses

  • Calendar events from the owner's own Google calendars, read through private calendar feeds.
  • With the owner's permission (Google scope calendar.events), the ability to create events on the owner's calendars.

How data is used and stored

  • Event data is used only to display the calendar and to create events the owner enters.
  • Data is stored only on the owner's device. It is not sent to any server operated by the app, sold, shared, or used for advertising.
  • Google sign-in credentials are stored only on the owner's device and can be revoked at any time from Google Account permissions.

Google API Services

Home Calendar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
